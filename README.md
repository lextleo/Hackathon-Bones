# 🦴 Hackathon Bones

A reusable project structure for hackathons, built to give new ideas a starting point instead of another empty folder.

The goal is simple: spend less time organizing files and more time building, testing, and bringing ideas to life.

## 🎯 Why this exists
Every hackathon starts with an idea, a deadline, and a lot to do. This repository is my attempt to create a structure I can reuse across projects, so I can get straight to the interesting part.

## 🗂️ What's inside

The basic bones for organizing a hackathon project:
- **Source code** — where the actual building happens.
- **Documentation** — problem statements, notes, and project details.
- **Assets** — images, diagrams, and other resources.
- **Setup & configuration** — the files needed to get things running.
- **Project planning** — tasks, ideas, and things to figure out.

*The structure will evolve as I build more projects and figure out what actually works.*

## 🚀 The idea
Clone it, adapt it, break it, improve it. Use what helps and change what doesn't.

This isn't a framework with strict rules. It's a starting point.

**Every great project needs bones. What you build on them is up to you.**
